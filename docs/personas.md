# 작성자 역할

정본 레코드를 실제 PLM 문서처럼 보이게 다시 쓰는 작성자들이다. 레코드마다 장비군 팀 안에서 한 명이 정해진다(`tools/assign_personas.py`).

## 다시 쓸 때 지키는 것

- 정본의 사실(현상, 원인, 조치, 버전, 식별자)을 더하거나 빼거나 바꾸지 않는다. 줄이거나 풀어 쓰는 것은 된다.
- `case_code`, `source_url`, `cause_basis`, `origin`은 그대로 둔다.
- 오타는 한국어 낱말과 띄어쓰기에 주로 넣는다. 영어 식별자 오타는 오타 빈도가 `높음`인 작성자만, 레코드당 많아야 한 번 넣는다.
- 정본에서 비어 있는 칸을 채우지 않는다. 작성자 습관으로 칸을 비우는 것은 `원인`이 `미상`일 때만 된다.
