# 원인 축 2단계: `c.env` 외부 조건·사건 아래 고르기

이 레코드는 1단계에서 `c.env`로 정해졌다. 이제 그 아래 노드 하나를 고른다.

## 할 일

1. 아래 '고르는 규칙'이 있으면 그 순서를 따른다. 없으면 정의·포함 기준이 가장 잘 맞는 노드를 고른다.
2. 더 아래 노드(세분류)가 있으면 거기까지 내려간다. 세분류를 가를 근거가 없으면 그 위 노드에서 멈춘다.
3. 하위를 가를 근거가 없으면 `c.env` 그대로 답한다.
4. 고른 노드의 포함 기준에 맞는 구절을 레코드 원문에서 그대로 복사해 evidence에 넣는다.

완료 기준: 레코드마다 `label`이 아래 목록 안의 값이고, `evidence`가 원문에 글자 그대로 있는 구절이다.

## 하위 노드

### `c.env.power` 전원·설비 이상 (Power or facility failure)

- 표준 대응: NORS Power Failure, Environment-Internal
- 정의: 상용 전원, 전원 설비, 냉방·축전지 같은 시설 조건이 정상 범위를 벗어났다.
- 포함: 정전, 전원 공급 중단·불안정, 축전지 방전, 냉방 정지, 실내 온도·습도 초과.
- 이웃과 가르기: 장비 안의 전원 모듈 고장은 c.hw.failure. 화재·침수 같은 사건이 전원을 끊었으면 c.env.physical.

### `c.env.physical` 외부 물리 사건·전파 조건 (External physical event or radio condition)

- 표준 대응: NORS Environment-External, Cable Damage; Avizienis natural·external physical fault
- 정의: 자연재해, 화재, 제3자의 공사·손상, 전파 간섭·약한 신호처럼 운용 조직 밖에서 생긴 물리 사건·조건이 원인이다.
- 포함: 지진·홍수·낙뢰, 화재, 제3자 공사로 cable 절단, 동물·차량·도난, 전파 간섭(불법 중계기 포함), 약한 무선 신호·coverage 부족.
- 이웃과 가르기: 악의적인 공격이면 c.env.attack. 무선 설정 값(gain, MCS, 주파수)이 틀렸으면 c.content.config.

### `c.env.attack` 악의적 공격 (Malicious attack)

- 표준 대응: Avizienis malicious fault; X.736 security alarm
- 정의: 누군가 의도적으로 서비스를 방해하거나 시스템에 침입했다.
- 포함: DDoS, 침입·악성 코드, 의도적인 신호 방해, 계정 탈취로 한 조작.
- 이웃과 가르기: 공격이 통한 이유가 코드의 검사·인가 결함이면 그 c.code 노드가 주이고 이 노드는 보조. 공격 없이 보안 결함만 보고됐으면 c.code.

### `c.env.service` 외부 서비스·기반 장애 (External service or infrastructure outage)

- 표준 대응: 대응 표준 없음(복수 문서 종류: CI 기록의 외부 저장소 장애, 장애 보고서의 상위 사업자·cloud 장애)
- 정의: 제품이나 작업이 기대는 외부 서비스·기반(상위 사업자 망, cloud 플랫폼, 외부 package 저장소·mirror, CI 기반)이 장애를 내거나 응답하지 않았다.
- 포함: 상위 사업자·연동망 장애, cloud 플랫폼의 유지보수 event, 외부 저장소·mirror 접속 불가, 외부 서비스 rate limit, CI node 공급 부족, message bus cluster의 일시 split brain.
- 이웃과 가르기: 외부 서비스의 새 버전이 동작을 바꿨으면 c.supply.dependency. 외부 시스템의 설정이 틀렸으면 c.content.config.

## 출력

`label`은 `c.env`, `c.env.power`, `c.env.physical`, `c.env.attack`, `c.env.service` 가운데 하나다. JSON 객체 하나만 낸다.

```json
{"results": [{"id": "<레코드 id>", "label": "<라벨>", "evidence": "<원문 구절>"}]}
```
