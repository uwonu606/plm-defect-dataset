# 문제점 축 2단계: `p.state` 구성요소·설비 상태 이상 아래 고르기

이 레코드는 1단계에서 `p.state`로 정해졌다. 이제 그 아래 노드 하나를 고른다.

## 할 일

1. 아래 '고르는 규칙'이 있으면 그 순서를 따른다. 없으면 정의·포함 기준이 가장 잘 맞는 노드를 고른다.
2. 더 아래 노드(세분류)가 있으면 거기까지 내려간다. 세분류를 가를 근거가 없으면 그 위 노드에서 멈춘다.
3. 하위를 가를 근거가 없으면 `p.state` 그대로 답한다.
4. 고른 노드의 포함 기준에 맞는 구절을 레코드 원문에서 그대로 복사해 evidence에 넣는다.

완료 기준: 레코드마다 `label`이 아래 목록 안의 값이고, `evidence`가 원문에 글자 그대로 있는 구절이다.

## 하위 노드

### `p.state.equipment` 장비·부품 고장 (Equipment or component failure)

- 표준 대응: X.733 event type equipmentAlarm
- 정의: 보드·port·fan·전원 모듈·광 모듈 같은 HW 구성 요소가 고장·이탈했거나 이중화의 한쪽을 잃었다.
- 포함: 보드·카드 고장 알람, fan 정지, 전원 모듈 고장, 광 모듈 이상, 이중화 상실(서비스 영향 없음), 장비 탈장.
- 이웃과 가르기: 환경·설비 조건(온도·전원 공급·습도)이 임계를 넘으면 p.state.environment. 고장 때문에 서비스가 끊기거나 멈췄으면 그 증상 노드가 주.

### `p.state.environment` 환경·설비 조건 이상 (Environmental or facility condition)

- 표준 대응: X.733 event type environmentalAlarm
- 정의: 온도·습도·전원 공급·냉방·함체 상태 같은 설치 환경·설비 조건이 임계를 넘었다.
- 포함: 함체·장비 온도 초과, 상용 전원 단절, 축전지 저전압, 냉방 정지, 함체 문 열림, 습도 초과.
- 이웃과 가르기: 장비 자체의 부품이 고장 났으면 p.state.equipment. 조건 때문에 서비스가 끊기거나 멈췄으면 그 증상 노드가 주.

## 출력

`label`은 `p.state`, `p.state.equipment`, `p.state.environment` 가운데 하나다. JSON 객체 하나만 낸다.

```json
{"results": [{"id": "<레코드 id>", "label": "<라벨>", "evidence": "<원문 구절>"}]}
```
